项目信息

项目是第一层级:角色、频道、任务、准则都归属当前项目,项目之间互不相干。

资源

项目使用的本地路径与 git 仓;本地路径若是 git 仓会自动绑定其远程仓库。有本地路径的资源可作为任务频道的工作目录。

角色

新增角色时可从全局角色模板导入后再调整；角色定位(人格)是"选人"的专长画像,供人类或主控调度时挑人,不是任务描述。启停开关只控制新任务，不中断当前运行，也不删除角色配置和历史；项目主控需先切换后才能停用。
