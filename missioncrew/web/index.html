自定义面板

面板由项目主控创建和维护:用一句话提需求(例如"建一个需求管理面板,上面是需求清单表格,下面实时显示进行中的任务"),主控通过控制动作完成创建或修改,过程在聊天频道全程可见。

项目信息

项目是第一层级:角色、频道、任务、准则都归属当前项目,项目之间互不相干。

资源

项目使用的本地路径与 git 仓;本地路径若是 git 仓会自动绑定其远程仓库。有本地路径的资源可作为任务频道的工作目录。

角色

角色定位(人格)是"选人"的专长画像,供人类或 @lead 调度时挑人,不是任务描述;任务简报由调度方结合项目章程在 @ 消息里撰写,定位文本平台不会改写。

频道

准则文档

项目准则以完整文档管理:每篇有标题、正文章节和文档库文件引用,启用的篇目会按顺序注入所有角色的执行上下文(开发规范、测试规范、部署说明等各成一篇)。

项目 Skills

Skill = 完整说明 + 文档库文件引用 + Runtime 适用范围;执行时按角色的 Runtime 注入,可用"按 Runtime 覆盖说明"给不同工具写不同指令(key 用 runtime id、adapter 名或 default)。

版本化文档库

所有角色都能把它当普通目录读写；平台在执行后自动记录版本。左侧是目录树,点开查看文档,右上角可编辑。

运行时(本机 Agent CLI 工具,全局共享)

这里只做工具的检测、启停与更新;成本、能力、档位等偏好在各项目的角色配置里定义(选工具 → 自动带出模型 → 配偏好)。
新建项目

创建后自动获得一套默认角色和 general 频道;章程、准则、验证规则到「项目设置」页补充。
新建任务

任务将按项目验证准则生成阶段计划(证据门禁/安全审查/人工审批)。
